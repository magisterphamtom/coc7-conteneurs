## Description courte
Sacs, valises et poupées russes pour L'Appel de Cthulhu 7e : n'importe quel objet CoC7 devient un conteneur où l'on glisse d'autres objets.

## Description longue (anglais)
Turn any item of the Call of Cthulhu 7th edition system into a container: a handbag, a backpack, a suitcase, a toolbox…

- **Drag and drop**: drop an item on the container's row on the character sheet to store it; open the container to see what is inside and drag things out again.
- **Russian dolls**: containers nest without limit (a lipstick in a compact in a handbag).
- **Weight and capacity**: contents are weighed (weight × quantity, nested containers included); the GM sets a maximum capacity per container by clicking the gauge.
- **Create containers in one click**: "New container" button in the Items directory or on any character sheet, with eight templates.
- **Themed per player**: the window follows each player's theme from the optional *CoC7 – Themed Chat Cards* module.
- **Safe**: nothing in CoC7 is modified. Contents live in the item's flags; disable the module and the container is a normal item.
- **Light**: a few milliseconds when a sheet opens, nothing on other windows.
- English and French interface.

## Description longue (français)
Fait de n'importe quel objet CoC7 un conteneur (sac à main, sac à dos, valise, mallette…) : on glisse les objets dedans, on les ressort, le tout reste sur la fiche. Poupées russes sans limite, poids et capacité réglée par le MJ, création en un clic, fenêtre au thème choisi par chaque joueur, aucune modification de CoC7.
